# Upstream engine render corpus

Fixed headless qualification for FilmCraft and EffectCraft intake. `corpus.json`
is the contract: which cases run, which committed fixtures they use, and the
tolerances that gate pin promotion. `library/tools/local_ci/corpus.py` runs it.

## Cases

| Case | Engine | What it proves |
|---|---|---|
| `filmcraft-solids-roundtrip` | FilmCraft | Five committed solid stills placed back-to-back; each rendered mid-frame carries the still's color in a 16 px center crop (max 1 LSB drift, PSNR floor 40 dB) and the full frame holds only the still color and letterbox black. Frame count and placement order are verified by pixels, not by CLI JSON. |
| `filmcraft-stereo-unity` | FilmCraft | The committed 1 s stereo WAV round-trips with 2 channels, duration within 0.05 s, and peak level within 0.5 dB of the fixture (unity gain, correct mapping). |
| `effectcraft-alpha-title` | EffectCraft | The driver's own tiny title (96x64, 5 frames, opacity fade): exact frame count, RGBA on every PNG, a fully transparent first frame, a visible last frame, a deterministic re-render (PSNR floor 60 dB), and alpha extremes surviving the ProRes 4444 encode. |

CLI command sequences reuse only surfaces proven by `native/ren-filmcraft`
and `native/ren-effectcraft` (`exec <command> <json> --compact`, `render
--seconds/--start/--end`, `run ... --empty --save-as`). Engine UI crates are
never built: qualification builds `--package filmcraft-cli` /
`--package effectcraft-cli` and the named test packages only.

## Performance

`filmcraft-edit-50` runs a fixed 50-op razor/inspect mix and records wall
time and peak child RSS alongside every case's own timings. Wall/RSS numbers
are recorded on every run; absolute per-case budgets gate promotion, while
ratios against the prior passed pin are review findings in the intake record,
never silent.

## Fixtures

All fixtures are synthetic and generated by `generate_fixtures.py` (stdlib
only; no third-party assets or licenses). To regenerate: run
`python3 generate_fixtures.py`, update the sha256 hashes in `corpus.json`,
and commit both. The runner refuses when a fixture on disk does not match its
recorded hash.
