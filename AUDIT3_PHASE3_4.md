## Bugs Found & Fixed

### 1. B-roll Source File Resolution (Step 3.02)
**File:** `library/steps/step_3_02_select_broll/post_bridge.py`
**Bug:** The logic for resolving `source_file` attempted to fallback to `path` or `file_path`, but failed to use `.get("source_file")` properly from the `catalog_clip`.
**Fix:** Explicitly added `.get("source_file")` as the primary fallback before checking `path` or `file_path` for robustness.

### 2. Subtitle Emphasis Case Mismatch (Remotion)
**File:** `remotion-subtitles/src/compositions/SubtitleOverlay/index.tsx`
**Bug:** The Remotion `SubtitleOverlay` component stripped punctuation but did not cast the word to lowercase when checking if it was included in `emphasisWords`. Since `emphasis_words` generated by Step 4.01 are strictly lowercase, mixed-case words (e.g. "Important") would fail the inclusion check and not be scaled up/colored properly.
**Fix:** Appended `.toLowerCase()` to the sanitized word check in `index.tsx`.

### 3. Manifest Compiler VFX Schema Mismatch (Step 5.04)
**File:** `library/steps/step_5_04_compile_manifest/step.py`
**Bug:** The `compile_manifest` function was attempting to extract VFX data using `vfx_data.get("vfx_plan", vfx_data.get("vfx_spec", []))`. However, the Step 4.03 output contract was updated to use `enhancement_spec`. While the DAG handled this translation in orchestrated runs, the local file-based compiler failed to read the correct key.
**Fix:** Updated `vfx_data.get` to prioritize `enhancement_spec`.

### 4. Manifest Compiler Subtitle Schema Mismatch (Step 5.04)
**File:** `library/steps/step_5_04_compile_manifest/step.py`
**Bug:** The `compile_manifest` function directly fetched `subtitle_entries` from `subtitle_data`. However, Step 4.01 output wraps the subtitle lists inside a `subtitle_plan` object to match the manifest contract. This caused local compilation to produce an empty subtitle array.
**Fix:** Modified `subtitle_data` reading to correctly extract `subtitle_entries` from inside the `subtitle_plan` object if present.

## Conclusion
Audit complete. Found and fixed schema mismatches between the outputs of Phase 4 and the compile_manifest reader, as well as a visual bug where capitalized words didn't properly receive emphasis styling.
