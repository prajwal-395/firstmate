What this player is, and is not

  • Source clip - the file on disk, seeked to the source frame under the playhead. Ungraded, no comps, no captions, no mix.
  • Rendered master - the pipeline's own export, seeked to timeline time. Graded and complete, and only as current as the last render.
  • Not reachable - a live mirror of Resolve's own viewer. There is no stream in the API. Single FRAMES are reachable - Timeline.GrabStill() returns the graded, conformed frame, and GetCurrentClipThumbnailImage() returns base64 on the Color page - but a grab costs seconds and round-trips the gallery, so a sequence of them is not playback and this plugin does not pretend otherwise.

The bridge to the pipeline's Python

One short-lived child process per request, JSON on stdin and stdout. Every call reports its own round trip.

What the JavaScript API exposes

What this plugin's own reads cost

Measured from inside the plugin host, over the loop's own reads - no extra call is made to Resolve in order to measure it. This is the plugin's half of "it cannot freeze Resolve"; the other half is an observer process timing Resolve from outside, which is what measures what the captain actually feels.
