# DA3 depth benchmark (GEO-001..012), measured 2026-10-16

Incumbent: Depth Anything V2 Small (`depth-anything/Depth-Anything-V2-Small`
@ `03876f8`, official `DepthAnything/Depth-Anything-V2` @ `a561b84`).
Candidates: DA3-Small / DA3-Base / DA3-Metric-Large at the pinned revisions
in `library/tools/depth_da3.py` (`VARIANTS`), official
`ByteDance-Seed/Depth-Anything-3` @ `3d835ec`, all Apache-2.0 per the
publisher cards (provisional; `vep-mu-license` is the authority).
Research-only variants (Giant, Large, nested, mono) were never downloaded
and never benchmarked; `load_variant` refuses them outside
`permitted_research` (GEO-012, tested hermetically).

Machine: captain's Mac, shared with other lanes - loaded-machine numbers.
Precision: full safetensors as shipped (all three under ~1.5B, per the
downloads approval). Process: `process_res=518`, torch MPS, one fresh
process per variant (honest cold load + process-peak RSS).
Stills were extracted read-only with ffmpeg and verified by eye: podcast
frames are seated talking-head close-ups (center-box foreground proxy
valid); Apple frames are handheld portrait (no foreground anchor claimed).

## Splits

- Calibration (settings chosen here): 5 podcast frames (LCATL0011
  t=10..50) + 3 Apple frames (IMG_1806 t=0.5/1.5/2.5).
- Held-out (run ONCE, after the shortlist): 3 podcast frames (LCATL0012
  t=15/30/45) + 1 Apple frame (IMG_1807 t=1.5). No frame was viewed or
  measured before its run except for the eye-check above.
- No human-label-gated measurement was used: every quality number below
  is a deterministic reading (rank agreement, Canny edge overlap,
  pose stillness, confidence ordering, ORB correspondence). No
  label-request was needed.

Direction note (GEO-008): every variant is read through the lane's
brighter-is-nearer orientation (`native_to_brighter_nearer`, refused when
unmeasured). DA3-Base's 0/3 held-out misses are proxy noise, not a flip:
margins there are -0.05..-0.09 while its calibration passes read
+0.05..+0.08 and DA3-Small's own calibration margins are +0.03..+0.05 -
the center-box proxy resolves ±0.08 on this studio material, and the
held-out framing moved the subject off-center (verified by eye: subject
right, laptop center-left). A global inversion would fail calibration
too. The native orientation stands as measured.

Metric note (GEO-003/008): DA3-Metric-Large returns `is_metric=False`,
no confidence and no extrinsics through this code path, so pose and
confidence are UNMEASURED for it (reported as absent, never zeroed).
Its native value distribution is meter-plausible (0.47-30.2, median 2.1
across studio + parking-lot frames) against 0.3-7.4 relative for
Small/Base - the relative-vs-metric distinction is preserved by preset
contract plus distribution, with the API flag gap recorded. It is not
the default; see decisions.

## Cost (loaded machine, fresh process per variant)

| signal | DAV2-Small | DA3-Small | DA3-Base | DA3-Metric-L |
|---|---|---|---|---|
| cold load (import + construct + weights + to MPS) | 17.2s | 30.1s | 42.3s | 61.0s |
| warm median / p90 over 8 mixed-aspect frames | 1.39 / 3.06s | 1.34 / 5.64s | 0.71 / 3.45s | 1.23 / 5.14s |
| warm landscape steady-state (podcast, excl. first) | 0.26s | 0.84s | 0.48s | 0.53s |
| joint pose pass (podcast batch) | n/a | 20.8s / 5 views | 6.8s / 5 views | 5.7s / 3 views, no pose out |
| process peak RSS | 0.35 GB | 0.25 GB | 0.47 GB | 0.87 GB |
| weights on disk | 99 MB | 131 MB | 516 MB | 1.2 GB |

First-frame compile dominates p90 (e.g. 13.3s small, 7.9s base);
portrait frames cost ~2x landscape (MPS shape recompile). Decode is
marginal-zero in the pipeline (M3g reads M2 thumbnails already decoded);
DA3 logs show the forward pass dominating each frame
(preprocess 0.02-0.4s + forward + convert, serialize <0.1s).
One outlier: the very first DA3-Small load of the earlier session
measured 2152s under heavy contention; a stage-timed fresh-process probe
(`probe_cold.py`) totals 29.4s (torch 4.3 + API import 12.8 + construct
0.5 + weights 0.2 + state 0.4 + to-MPS 1.7 + first infer 9.5), so the
outlier is machine contention, not the model - reported, not used.

Survey arithmetic at the M2 cadence (~2 Hz): DAV2's documented ~9.5 min
per 68-minute source becomes ~20-25 min under DA3-Small landscape
steady-state - accepted under EVAL-036 (accuracy + new capabilities for
compute), one source at a time, cached by content digest.

## Searchability (GEO-010)

`summarize_interval` carries near/mid/far terciles, mean confidence,
camera state and depth_kind/unit per interval; `select_intervals`
filters those records by camera state, depth kind and minimum
confidence (pure, tested). Full index integration belongs to the
retrieval lane; this is the record it queries.

## Decisions (EVAL-032)

- **DA3-Small: ADOPT** as the depth backend behind the existing
  estimator protocol (GEO-001). Best edge agreement on both splits,
  clean direction on both splits, the only calibrated confidence,
  pose on the tripod-correct verdict, lightest weights/memory.
  Integrated as the default with the incumbent retained as fallback.
- **Depth Anything V2 Small: RETAIN BASELINE** (fallback; never
  removed). Still the fastest landscape steady-state and the
  fallback when DA3 assets are absent.
- **DA3-Base: CONDITIONAL FALLBACK** (GEO-002, gated on Small's gains
  which materialized). Fastest warm overall, but direction is marginal
  on held-out framing and its confidence is uncalibrated (rho 0.1).
  Wired and selectable; not the default.
- **DA3-Metric-Large: CONDITIONAL FALLBACK** for metric-valued tasks
  only (GEO-003). No pose/confidence through this path and the metric
  flag reads False, so it never enters M3g (which stores normalized
  relative medians); its unit travels as meters-by-preset wherever a
  metric consumer is built.
- **Research-only variants: RESEARCH-ONLY** (GEO-012). No download, no
  benchmark, refusal tested; Personal-research use only.
